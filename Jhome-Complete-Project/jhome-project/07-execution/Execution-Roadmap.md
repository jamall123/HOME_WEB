## الجزء الأول: الحالة الراهنة (نقاط القوة والضعف)

### ✅ ما هو جاهز
- موقع sudanfree.com احترافي ومتكامل.
- تطبيق SudFree على Google Play (100+ تحميل).
- حساب المطور (Ahmed Tech2 — يحتاج مراجعة).
- الهوية البصرية (Jhome).
- فريق العمل الأساسي: جمال (CEO + مطور).

### ❌ ما هو ناقص
- لوحة تحكم للموقع (لا يمكن نشر مدونات/أخبار/قصص ديناميكياً).
- نظام CMS لإدارة المحتوى.
- استراتيجية تسويقية مكتوبة.
- حضور إعلامي للمؤسس.
- شراكات مؤسسية.
- مستثمر أو تمويل إضافي.
- مستخدمون نشطون (MAU ضعيف).

## الجزء الثالث: خطة الـ 12 شهر

### الشهر 1 (الآن) — البنية والإطلاق
**الهدف:** نظام CMS يعمل + 5,000 تحميل + 1,000 MAU

**المهام الرئيسية:**
1. ✅ نشر نظام إدارة المحتوى (Firebase + لوحة التحكم).
2. ✅ كتابة 5 مقالات و 3 قصص نجاح.
3. ✅ إطلاق حسابات Jhome على السوشيال.
4. ✅ أول 1,000 تحميل إضافي من إعلانات فيسبوك.
5. ✅ تسجيل 50 حرفي مبدئياً.

### الشهر 2 — النمو الأولي
**الهدف:** 15,000 تحميل + 3,000 MAU

**المهام:**
1. حملة إعلانية ثانية (Google Ads + TikTok).
2. شراكة مع مؤثر سوداني واحد على الأقل.
3. إطلاق برنامج "سفراء SudFree" — 5 سفراء في الخرطوم.
4. مقالان أسبوعياً في المدونة.
5. إطلاق الإصدار v2.0 من التطبيق بتصنيف صحيح (Business).

### الشهر 3 — تعميق الثقة
**الهدف:** 30,000 تحميل + 7,000 MAU + 4.5 نجوم

**المهام:**
1. إضافة خاصية "العقد الرقمي" بين العميل والحرفي.
2. نظام تقييم محسّن مع صور.
3. إطلاق بوت Telegram للإعلانات.
4. أول لقاء مجتمعي (Meetup) في الخرطوم.
5. شراكة مع جامعة الخرطوم أو أم درمان الأهلية.

### الشهر 4-6 — التوسع الأفقي
**الهدف:** 80,000 تحميل + 20,000 MAU + إيرادات 500$/شهر

**المهام الرئيسية:**
1. **منتج:** إضافة نظام الدفع الإلكتروني (يدوي ثم أوتوماتيك).
2. **تسويق:** دخول أسواق إضافية (مدن: بورتسودان، الأبيض، مدني).
3. **شراكات:** عقد واحد مع منظمة دولية (UNDP/WFP).
4. **فريق:** توظيف أول موظف بدوام كامل (مدير محتوى / تسويق).
5. **منصة:** إطلاق Debt Manager.

### الشهر 7-9 — التمويل والبناء المؤسسي
**الهدف:** 150,000 تحميل + 50,000 MAU + إيرادات 2,000$/شهر

**المهام:**
1. **التمويل:** التحضير لجولة Angel (10K-50K$) — إنشاء Pitch Deck.
2. **فريق:** توظيف CTO + مصمم UI/UX.
3. **منتج:** إطلاق Injaz (الإنتاجية).
4. **تسويق:** سلسلة "Building Jhome in Public" — فيديو أسبوعي.
5. **شراكات:** استراتيجية مع شريك خليجي واحد (لجمهور المغتربين).

### الشهر 10-12 — التأسيس للسوق الإقليمي
**الهدف:** 250,000 تحميل + 80,000 MAU + إيرادات 5,000$/شهر

**المهام:**
1. **منتج:** تطبيق SudFree v3.0 (بـ AI في التوصيات).
2. **دولي:** إطلاق نسخة Beta من SudFree للسودانيين في مصر.
3. **فريق:** 4-6 موظفين بدوام كامل.
4. **محتوى:** 50+ مقال + 100+ فيديو قصير.
5. **استراتيجية:** بدء دراسة جدوى Jhome Construction.

## الجزء السابع: قائمة المهام اليومية (Checklist)

### لكل يوم عمل:

**الصباح (ساعتان):**
- [ ] مراجعة الإشعارات (Firebase، إيميل، واتساب).
- [ ] قراءة المقالات اليومية (تقنية / ريادة أعمال).
- [ ] تخطيط مهام اليوم.

**وقت البناء (4-6 ساعات):**
- [ ] تطوير منتج أو إصلاح خطأ.
- [ ] كتابة محتوى (مقال، منشور، إلخ).
- [ ] العمل على أولوية الأسبوع.

**وقت المجتمع (ساعة):**

- [ ] متابعة المجموعات والقنوات.

**وقت الاستراتيجية (ساعة):**
- [ ] قراءة أرقام لوحة التحكم.
- [ ] مراجعة تقدم الأسبوع.
- [ ] تخطيط للغد.

**المساء (نصف ساعة):**
- [ ] تحديث المهام في Linear.
